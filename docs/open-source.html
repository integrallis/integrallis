01Projects

Nine projects, one standard of evidence.

Each one exists because a piece of the research needed it. The four at the top compose into a locally owned AI runtime and are documented in depth on the Java AI page; the rest stand alone.

Java 25Retrieval

Vectors

Embedded similarity search that runs inside your process: persistent collections, metadata filtering applied during the search, ANN indexes, and adapters for Spring AI and LangChain4j. Takes full advantage of the Java 25 Vector API.

View project ↗Documentation ↗
Java 25Inference

Models

In-process small-language-model inference — no Python, no model server, no sidecar. Pure Java, native FFM, and Apple platform backends, selected from recorded capability evidence. Rides on Vectors.

View project ↗Documentation ↗
JVMDistribution

ModelJARs

Qualified, versioned model artifacts resolved through ordinary JVM dependency coordinates, with provenance and checksums verified against upstream weights. Declare a model the way you declare any other dependency.

modeljars.org ↗

Java 25Agentic memory

Memory

An open agentic memory layer: working and long-term stores, retrieval orchestration, consolidation, and conflict resolution. Framework-neutral at the core, with Spring AI, LangChain4j, and MCP surfaces.

pleat

Ribbon filters with pleated construction: a one-pass, cache-window reordering that builds space-optimal filters at close to Bloom-filter speed, roughly twice as fast as building in arrival order at scale. Companion to the Ribbon Catches Bloom paper.
